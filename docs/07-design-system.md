# 07 — Design system

Direction: clean and professional with creative warmth — card-first calm structure, soft depth, confident color blocking, a light papery texture. Adult, grounding, enjoyable; not a health/meditation app, not childish. Whitespace does the organizing; color does the delighting.

## Color tokens

Values live in `apps/mobile/src/theme/tokens.ts` and the shared Tailwind preset in `packages/config/tailwind`. No raw hex in components.

Cornflower is the hero; ink is the workhorse text and dark color; leaf, sun and peach are pops. No muddy or gray-leaning mixes. Body text is always ink on paper or white. Cornflower, leaf and peach on white are for large text, fills and accents only — check AA (4.5:1) before using colored text under 18px.

| token             | use                                                  |
| ----------------- | ---------------------------------------------------- |
| `paper`           | app background (warm off-white, not gray)            |
| `surface`         | cards                                                |
| `hairline`        | borders, dividers                                    |
| `outline`         | edges of controls that must read as tappable (3:1)   |
| `ink`             | primary text, dark surfaces (warm dark blue)         |
| `ink-soft`        | secondary text                                       |
| `cornflower`      | primary actions, selection, Next accent              |
| `cornflower-deep` | pressed states, strengthened-goal fill, text on tint |
| `cornflower-tint` | introduced-goal wash, selected pills                 |
| `leaf`            | Strengthen accent, success                           |
| `leaf-tint`       | correct answers, tips, Strengthen card tint          |
| `sun`             | highlights, calendar marks, week dots, celebrations  |
| `sun-tint`        | examples, resources, practiced days                  |
| `peach`           | Go further accent, "Put to use" celebration          |
| `peach-tint`      | selected answers, Go further card tint               |

Semantic mappings:

- **Sections**: Next → cornflower · Strengthen → leaf · Go further → peach. Done today is one color across sections — `sun` — while the section color stays with the section: the heading gets a `sun` check and the day's count, a done card takes its section's tint, and its time chip becomes a `sun` "Done today" chip. When a section turns done while Today is in view, the check springs in after the screen settles; at mount, or with Reduce Motion on, it's simply there.
- **Week dots** (Today title, `01` §3): 8px, `sun` for a day done, a `sun` ring on `sun-tint` for one still to go. When today is one of the days done, its dot is 14px with an `ink` check, a small Section check. The calendar's streak and Path's progress line are `ink-soft` captions — counts, not decorations.
- **Goal status**: `not_started` = white card + hairline · `introduced` = cornflower-tint fill · `strengthened` = cornflower-deep fill, light text · `applied` ("Put to use") = the strengthened treatment + a peach edge glow — celebratory, since going further is optional.
- Errors are rare; use ink text and a peach accent, no harsh red.

## Typography

- **Arvo** — headings and display. 700 for screen titles and section headings, 400 for card titles.
- **Outfit** — everything else. 400 body, 500 labels and buttons, 600 emphasis.
- Scale: display 28 · title 22 · heading 17 · body 16 · secondary 14 · caption 12, with generous line height (~1.45 body). Text is minimal by principle; a screen rarely needs more than three levels.

## Texture & depth

- A paper-grain overlay at 3.5% opacity — felt, not seen — rendered **once at the root**, over every screen and under every modal, so no screen has to remember it.
- Soft watercolor washes (`Wash`): a palette color thinned to about a fifth, fading to nothing, bleeding off an edge. Two or three at a time, at the edges — never one centered shape behind the words. Used sparingly: the intake welcome, empty states (`EmptyState`) and the summary page. Strength is one number per tone, `CORE_ALPHA` in `Wash`: `tint` at rest, `flush` for a celebration.
- The raster assets — grain, app icon, splash mark, Android icon layers — are generated by a script rather than drawn by hand; regenerate them instead of editing a PNG.
- The mark is a lowercase Arvo `t` in `paper` on a cornflower field, with a `sun` spark at its shoulder.
- Depth: cards with soft wide shadows (`ink` at 6–8% alpha, large radius), 16–20px corner radius, 999 for pills. One elevation step — no stacked shadows.

## Components

Shared components live in `apps/mobile/src/components`; reuse one before adding another.

- Activity blocks each have a component mapping 1:1 to the block kinds in `05`. Interactions animate gently (spring, 200–300ms): feedback through motion and color, not confetti.
- **Summary celebrations** (`features/activity-player/celebration.tsx`): arriving at a summary gets one palette-only moment by section, over 2½–3½ seconds — Next: the progress bar's segments light `sun` in turn; Strengthen: palette dots drift up and fade; Go further: washes bloom and settle back to their tint. Each plays once per arrival, and none plays with Reduce Motion on.
- Motion uses React Native's `Animated` (`PressScale`, `FadeIn`, `Sheet`); nothing needs Reanimated. Create a shared `Animated.Value` with `useState(() => …)`, not `useRef` — reading a ref during render is a lint error under the React Compiler rules.
- `TextField` takes a `limit` for any field whose text reaches a prompt: a quiet count near the limit, a peach border past it, and the screen holds back sending rather than cutting the text (`04` §Untrusted text).
- A `testID` prop exists for the Maestro flows (`10` Tier 6), not for styling.
- Header icon actions sit on the right, `ink-soft` at 22px with `hitSlop={10}`. Every tab carries the **⚙** to settings (`SettingsButton`) last in its top-right row; a tab's settings live behind the ⚙, not in its scroll (`01` §7).

## Web

The app is laid out for a phone, and the web build keeps it that way. In a window wider than 580px it sits centered in a 580px column on paper, with a hairline at each edge (`AppFrame`, `components/app-frame.web.tsx`) — about 70 characters of body text to a line. It is not a desktop layout: no sidebar, no grid, no second set of screens to keep in step. Modals render outside the frame, so `Sheet` and `InfoDialog` take the column's width themselves (`columnStyle`). The native `app-frame.tsx` is a pass-through. The tab bar is 60px tall on web, where there's no bottom inset to lend it room.

## Voice

Short, warm, plain, adult. Sentence case everywhere. No exclamation-mark cheerleading, no help-text paragraphs — if a screen needs explanation, redesign it. Praise only when specific and earned. Never patronize or assume: activity in the app is not the sum of what someone knows, so write "you've covered X in thinkering", never "you haven't learned X yet" (the same rule applies to generated content, `04`).

## Implementation

- Fonts via `@expo-google-fonts/arvo` and `@expo-google-fonts/outfit`; the same families are self-hosted on the landing page, whose display sizes live in `apps/web/tailwind.config.cjs`.
- Dark mode is out of scope for now; the tokens are structured so it can be added as a second palette.

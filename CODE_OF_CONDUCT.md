# Code of conduct

thinkering follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Harassment and personal attacks aren't welcome in issues, pull requests, the feedback board or anywhere else the project gathers.

To report a problem, email **hello@thinkering.app**. Reports are kept confidential.
